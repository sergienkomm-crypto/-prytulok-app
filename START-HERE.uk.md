# Почніть тут

## Запуск

Потрібен Node.js 24 LTS (від 24.3). У хмарі працюйте в `/workspace/-prytulok-app`. Кожне завдання ізольоване: використовуйте наявний checkout; не створюйте Git worktree без окремого запиту.

```bash
npm ci
npm run check
npm test
npm run export:android
```

`check` запускає TypeScript і ESLint; `test` — шість тестів фільтрації, обраного, заявок і валідації. Android export компілює JavaScript/Hermes у `dist/android` — це не APK.

Локальний Metro у хмарі:

```bash
EXPO_OFFLINE=1 npm start -- --localhost --max-workers 2
```

Браузерна перевірка:

```bash
EXPO_OFFLINE=1 npm run web -- --localhost --port 8082 --max-workers 2
```

Команди з `EXPO_OFFLINE=1` наведено для Bash. Вони не потребують доступу до API Expo. Фото й іконки постачаються локально. `CI=1` можна додати для автоматизованого запуску, але тоді Metro не стежить за змінами файлів.

## Перевірка на Android

На Windows установіть Git та Node.js 24 LTS. Отримайте актуальний код із GitHub у **нову** папку, зберігши попередній `my-app`. Для цієї версії використовуйте гілку `codex/prytulok-ui-prototype`; `main` містить початкову основу. Локальні правки самі не синхронізуються з GitHub.

```powershell
git clone --branch codex/prytulok-ui-prototype https://github.com/sergienkomm-crypto/-prytulok-app.git prytulok-preview
cd prytulok-preview
npm ci
npm start -- --lan
```

Телефон і комп’ютер мають бути в одній Wi-Fi мережі. В Expo Go із підтримкою SDK 58 відскануйте QR-код. Команда `npm run android` потребує ADB-пристрою або емулятора. Доступ телефона до Metro у хмарі не перевірявся.

## Що реалізовано

- Чотири кроки онбордингу, вибір виду, сумісності та невеликого розміру → персоналізована добірка.
- П’ять вкладок: персональна головна, стрічка, пошук, чати, акаунт.
- Візуальні фільтри, кількість реальних збігів у наборі з 8 mock-тварин, очищення, порожня видача.
- Профіль тварини, обране, здоров’я та інформація про притулок.
- Демо-реєстрація через Google, Apple, email або телефон лише під час персональної дії. Після неї відновлюється обране, заявка або чат.
- Коротка анкета, перевірка контактів і згоди, анімація успіху. Заявка створює пов’язану розмову; повторна заявка не дублюється.
- Чати з прив’язкою до тварини, локальне надсилання повідомлень, фільтри «Усі / Непрочитані / Заявки».
- Підтримка: сума, разово/щомісяця, демо-підтвердження, анімація успіху; тварина з’являється в «Підтримую».
- Локальне збереження через AsyncStorage. Для повторної демонстрації: Акаунт → Налаштування → Почати демонстрацію спочатку.

Для нового користувача «Обране», «Підтримую» й повідомлення порожні. Вони наповнюються його діями; це навмисна відмінність від заповнених референсів.

## Межі прототипу

Немає справжньої авторизації, SMS, хмарного акаунту, платежів, підписок чи надсилання заявок притулкам. Анкета перевіряється для демонстрації переходу; на сервер вона не відправляється. Усі ідентичності та тварини вигадані. Вихід з акаунту не очищує локальну демонстрацію; для цього є окрема дія скидання.

Створення власних оголошень, реальне редагування профілю, завантаження фото та backend залишені на наступні етапи. Галерея показує лише наявне фото конкретної тварини, без підміни фото іншими тваринами. У заголовку, онбордингу й конфігурації іконки використано адаптовану версію наданого логотипа з прозорим тлом. Типографіка — системний sans-serif. Компоненти та кольори централізовані в `src/components/ui.tsx` і `src/theme.ts`.

## Наскрізний UI-тест

Запустіть Metro для web на порту 8082, потім в іншому терміналі:

```bash
npx playwright install chromium
npm run test:ui
```

Якщо Chromium уже встановлений, у Bash можна вказати `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:ui`. Змінна `PROTOTYPE_URL` дозволяє обрати інший тестовий сервер. Знімки екранів потрапляють в ігноровану папку `test-results/`.

Тест проходить онбординг, добірку, відновлення дії після email- та Google-реєстрації, обране, помилки анкети, заявку, чат, помилки суми, демо-підтримку, перезавантаження, фільтри, порожню видачу та ширини 320/390/430 px. Перевірка у браузері не замінює ручний тест на фізичному Android.

## Діагностика Expo

```bash
NODE_USE_ENV_PROXY=1 npm run doctor
npm audit
```

Попередній onboarding дав Expo Doctor 18/20: перевірки схеми Expo та React Native Directory блокувалися мережею. Це не повний успішний Doctor; після застосування мережевих налаштувань його слід повторити. Попередній аудит мав 24 moderate, без high/critical; це результат до розширення UI. Не вимикайте TLS і не запускайте примусові виправлення залежностей.
