# Логотип

Логотип із собакою, котом та помаранчевим серцем надано власником продукту в чаті. `logo.png` — адаптована версія з прозорим тлом, підготовлена інструментом редагування зображень за цим референсом; це не оригінальний вихідний файл. Використовується у заголовках, онбордингу та конфігурації іконки Expo.

Коли буде доступний вихідний SVG/PNG, його можна підставити за тим самим шляхом для точного відтворення оригіналу.
